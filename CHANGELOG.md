# Changelog

## 1.0.0 (2026-11-26)
- Initial public release of `@bloume/id`.
- 104 deterministic browser & hardware signals (Canvas, WebGL2, WebGPU, Audio, Fonts, Math, Screen/HDR, Anti-Spoof).
- Zero runtime dependencies (`dependencies: {}`).
- Dual-API compatibility: ThumbmarkJS Pro & Fingerprint.com (FingerprintJS Pro) schemas.
- Server-side verification client (`@bloume/id/server` -> `BloumeIDServer`).
- ESM, CJS, UMD (`window.BloumeID`), and full TypeScript `.d.ts` declarations.
